## U-20261116-09 · 2026-11-16 · Control flow in action files: WR_if, loops, WR_try, WR_retry_block · #feature #executor #flow

- **What**: blocks decide which actions of an action file run (second part of `progress.md` #28).
  - **Commands**: `WR_if` (`condition`, `then`, `otherwise`), `WR_for_each` (`items`, `do`, `var`, `index_var`), `WR_repeat` (`times`, `do`, `index_var`), `WR_while` (`condition`, `do`, `max_iterations`, required), `WR_try` (`do`, `on_error`, `always`), `WR_retry_block` (`do`, `retries`, `backoff`), `WR_fail` (`message`), `WR_assert_var` (`var`, `op`, `value`).
  - **Conditions** (`utils/flow/conditions.py`) are JSON objects and are never evaluated as code: `{"var", "op", "value"}`, `{"succeeds": action}`, `{"all": […]}`, `{"any": […]}`, `{"not": …}`, or a plain value. Operators: `eq`, `ne`, `gt`, `ge`, `lt`, `le`, `contains`, `in`, `startswith`, `endswith`, `exists`, `truthy`, `falsy`.
  - **`Executor.run_nested`** runs the actions a command holds: each passes `attempt` (gates, placeholders, retry policy, span), the first failure stops the block and is raised as it is. `WR_capture` and `WR_render_template` use it too.
- **Decisions**:
  - The argument names are `otherwise`, `on_error`, `always` and `var`, not `else`, `catch`, `finally` and `as`: those are Python keywords and cannot be parameters of the command.
  - No regular-expression operator: a pattern from an action file would run unbounded on the executor's thread.
  - A failed block is one failed record. `execute_one` would have wrapped the error and taken a failure screenshot at every nesting level.
  - Limits: 100,000 rounds for `WR_repeat` and `max_iterations`, 100 for `retries`.
  - Loop variables and `${error}` live in a `VariableStore.scope` frame and end with their block; a value set with `WR_set_var` inside a block stays.
- **Result / numbers**: 567 `WR_*` commands (559 before).
- **Files**: `je_web_runner/utils/flow/blocks.py`, `conditions.py`, `je_web_runner/utils/executor/_flow_commands.py`, `_authoring_commands.py`, `action_executor.py`, `test/unit_test/test_flow_blocks.py`, `test/unit_test/test_authoring_commands.py`, `docs/reference/`, `architecture.md`, `progress.md`, the three READMEs, `docs/source/{Eng,Zh}/doc/action_executor/action_executor_doc.rst`, `docs/source/{Eng,Zh}/doc/mcp_claude/mcp_claude_doc.rst`.

## U-20261116-11 · 2026-11-16 · File meta: setup, teardown, vars, skip, retries; fail-fast · #feature #executor #flow
